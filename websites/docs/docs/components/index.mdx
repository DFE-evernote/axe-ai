# Components

`@axe-ai/ui` provides a set of React components designed for AI-powered chat interfaces.

## Installation

```bash
pnpm add @axe-ai/ui
```

## Usage

Import components and styles in your project:

```tsx
import { ChatBubble } from '@axe-ai/ui';
import '@axe-ai/ui/styles.css';
```

## Available Components

| Component | Description |
|-----------|-------------|
| [ChatBubble](/components/chat-bubble) | Chat message bubble with user/assistant styling |
